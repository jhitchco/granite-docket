    Projects come from planning board, ZBA and select board records, which start in mid-2023 for most towns (a few older projects appear because later meetings cite them). Each was checked against its source text and duplicates merged; first seen is the earliest meeting that names it. Records almost never state construction cost, so dollar value comes from the permit layer. Pins marked approx. sit at the street or town center. Permits: U.S. Census Building Permits Survey, units in 5+ unit buildings; towns that don't report are missing.
